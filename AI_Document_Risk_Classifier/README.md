# AI Document Risk & Compliance Classifier

## Overview
AI Document Risk & Compliance Classifier is a Machine Learning-based web application developed using Python and Streamlit. It classifies uploaded or manually entered documents into **High Risk** or **Low Risk** categories based on their content.

## Features
- Upload PDF and TXT documents
- Manual text input
- AI-based document classification
- Sensitive keyword detection
- Prediction explanation
- Dashboard with statistics
- Pie chart visualization
- Classification history
- Download history as CSV

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib
- PyPDF2
- Joblib

## Machine Learning Model
- Algorithm: Logistic Regression
- Text Vectorization: TF-IDF Vectorizer
